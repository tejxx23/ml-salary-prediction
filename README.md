# 💰 Salary Prediction using Multiple Linear Regression

## 📌 Project Overview

This project uses Machine Learning to predict an employee's salary based on:

- Experience
- Age
- Hours Worked

A Multiple Linear Regression model is trained using Python and Scikit-learn.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- GitHub

## 📊 Machine Learning Model

The project uses:

**Multiple Linear Regression**

The dataset contains the following features:

| Feature | Description |
|---|---|
| Experience | Years of work experience |
| Age | Age of the employee |
| Hours_Worked | Working hours |
| Salary | Target variable |
